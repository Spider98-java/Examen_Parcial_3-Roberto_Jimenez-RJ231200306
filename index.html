¿Qué es una Base de Datos?

Una base de datos es un conjunto organizado de información estructurada, almacenada electrónicamente en un sistema informático, diseñada para facilitar el acceso, gestión y actualización de datos.

Tipos de Bases de Datos

  • Relacionales (SQL)
  • No Relacionales (NoSQL)
  • Orientadas a Objetos
  • Distribuidas
  • En la Nube

Modelo Relacional

  • Tablas (Relaciones)
  • Filas (Tuplas)
  • Columnas (Atributos)
  • Claves Primarias
  • Claves Foráneas

SQL vs NoSQL

  • SQL: Estructura fija
  • SQL: ACID compliant
  • NoSQL: Esquema flexible
  • NoSQL: Escalabilidad horizontal
  • Cada uno con sus ventajas

Motores Principales

  • MySQL (Oracle)
  • PostgreSQL (Open Source)
  • SQL Server (Microsoft)
  • MongoDB (NoSQL)
  • Oracle Database

Ciclo de Vida

  • 1. Análisis de requisitos
  • 2. Diseño conceptual
  • 3. Diseño lógico
  • 4. Implementación
  • 5. Mantenimiento

Ejemplos Reales

  • Redes Sociales (usuarios)
  • E-commerce (productos)
  • Banca (transacciones)
  • Salud (pacientes)
  • Educación (estudiantes)
